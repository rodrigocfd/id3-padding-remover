# ID3 Fit

A native Windows editor for [ID3 v2.3.0](https://id3.org/id3v2.3.0) tags in MP3 files.

![Screenshot](screenshot-50.png)

## Dependencies

This project is written in Go and uses [Windigo](https://github.com/rodrigocfd/windigo) library.
